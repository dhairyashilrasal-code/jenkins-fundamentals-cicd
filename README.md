



Learn Jenkins concepts and implement a CI/CD pipeline for a Python application using Git, GitHub, pytest, and Docker.


- Understand Jenkins controller, agents, executors, jobs, and plugins.
- Compare Freestyle jobs and Pipeline jobs.
- Create and configure Jenkins jobs.
- Automate dependency installation and Python tests.
- Build a Docker image through a Jenkins pipeline.
- Deploy and verify the application.
- Practise troubleshooting failed pipeline builds.


1. Checkout source code
2. Install dependencies
3. Run automated tests
4. Build Docker image
5. Deploy application
6. Verify application health


- Git and GitHub
- Jenkins
- Python and pytest
- Docker
- VS Code
